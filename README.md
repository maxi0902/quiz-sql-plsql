# Quiz SQL y PL/SQL

Quiz de alternativas para repasar **Base de Datos 1** (modelo relacional y SQL) y **PL/SQL en Oracle** (cursores, RECORD y VARRAY, excepciones, funciones, procedimientos, packages y triggers), usando el caso **Renta House**.

## Cómo se usa

- Elige el tema (Todo, SQL o PL/SQL) y la cantidad de preguntas.
- Responde con A, B, C o D. Si no sabes, aprieta **«No lo sé»**: al final del quiz ese tema aparece explicado desde cero, con un ejemplo.
- Lo que fallas o no sabes se vuelve a preguntar más adelante, de otra forma.
- Al terminar puedes practicar solo los temas que te costaron.

Atajos de teclado: `A`–`D` (o `1`–`4`) para responder, `N` para «No lo sé» y `Enter` para seguir.
